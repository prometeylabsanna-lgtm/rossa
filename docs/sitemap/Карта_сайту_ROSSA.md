# Карта сайту ROSSA

Сайт-вітрина м’яких меблів **ROSSA**.

Відвідувач дивиться продукцію → натискає **«Замовити»** на картці однієї моделі → залишає контакти. Менеджер бачить заявку в адмінці і зв’язується сам.

| Що на сайті | Коротко |
|---|---|
| Продукція | Дивани (модульні, кутові, прямі), ліжка, пуфи |
| Ціна | Базова «від … грн» → зростає при виборі дорожчої тканини |
| Тканина / колір | Спочатку тканина (ціна), потім відтінок; кружечки як у Pufetto; окреме фото на кожен відтінок |
| Замовлення | «Замовити» + фіксація обраної тканини, відтінку й перерахованої ціни |
| Головна | Відео на першому екрані |
| Сторінки | Співпраця, Про нас, Контакти |
| Мови | Українська, російська |

Наповнення товарів — **вручну через адмінку**

## 1. Каталог продукції (категорії)

Повна структура розділу **«Продукція»**:

```
Продукція
│
├── Дивани
│   ├── Модульні
│   ├── Кутові
│   └── Прямі
│
├── Ліжка
│
└── Пуфи
```

### 1.1. Таблиця категорій

| Рівень | Назва (UA) | URL | Що показує |
|---|---|---|---|
| 0 | Продукція (огляд) | `/katalog/` | Плитки всіх категорій 1 рівня |
| 1 | Дивани | `/katalog/divany/` | Усі дивани + плитки підкатегорій |
| 2 | Модульні | `/katalog/divany/modulni/` | Лише модульні дивани |
| 2 | Кутові | `/katalog/divany/kutovi/` | Лише кутові дивани |
| 2 | Прямі | `/katalog/divany/pryami/` | Лише прямі дивани |
| 1 | Ліжка | `/katalog/lizhka/` | Усі ліжка |
| 1 | Пуфи | `/katalog/pufy/` | Усі пуфи |
| — | Картка товару | `/tovar/{slug}/` | Одна модель + форма «Замовити» |

### 1.2. Правила категорій

1. Кожен товар належить **одній** категорії 1 рівня (Дивани / Ліжка / Пуфи).
2. Диван **обов’язково** належить до однієї підкатегорії: модульний / кутовий / прямий.
3. Ліжка і пуфи на старті **без** підкатегорій (можна додати пізніше в адмінці без зміни логіки сайту).
4. У меню шапки пункт **«Продукція»** відкриває список категорій (Дивани → підпункти Модульні / Кутові / Прямі, далі Ліжка, Пуфи).
5. На головній блок **«Наша продукція»** — три плитки: Дивани, Ліжка, Пуфи.
6. Фільтр «тип дивана» на `/katalog/divany/` дублює підкатегорії (швидкий перехід без зміни логіки URL).

### 1.3. Картка в сітці каталогу

Для будь-якої категорії однакова картка (референс UX: Pufetto):

- велике фото моделі (змінюється при виборі відтінку);
- під фото — **кружечки відтінків** (як у Pufetto): клік по кружечку змінює фото на відповідне (окремий кадр моделі на цей колір);
- бейджі NEW / TOP / Хіт (з адмінки);
- назва моделі;
- підпис категорії (напр. «Дивани · Кутові», «Ліжка», «Пуфи»);
- ціна **«від … грн»** (мінімальна серед доступних тканин цієї моделі; у сітці тканину не обирають — лише прев’ю кольорів);
- клік по назві / фото (не по кружечку) → картка товару.

Якщо в моделі немає відтінків — кружечки не показуються, лише одне фото.

---

### 1.4. Тканина → відтінок → ціна (логіка конфігуратора)

Порядок вибору **завжди**: спочатку **тканина** (впливає на ціну), потім **відтінок** (змінює фото).

| Крок | Що обирає клієнт | Що змінюється |
|---|---|---|
| 1 | Тканина (напр. категорія / колекція тканини) | **Ціна** моделі: базова або вища для дорожчої тканини |
| 2 | Відтінок (кружечок кольору в межах обраної тканини) | **Фото** моделі: окреме реалістичне фото на цей відтінок |

**Правила:**

1. У кожної моделі — список доступних **тканин**. У кожної тканини — своя **ціна** (або націнка до базової).
2. У кожної тканини — список **відтінків** (кружечки: колір swatch + назва UA/RU).
3. На **кожний відтінок** в адмінці завантажується **окреме фото** моделі в цьому кольорі (не програмна перефарбовка).
4. Зміна тканини → перерахунок ціни одразу; список відтінків оновлюється під обрану тканину; якщо попередній відтінок недоступний — береться перший доступний.
5. Зміна відтінку → підміна головного фото / галереї на фото цього відтінку; ціна **не** змінюється від відтінку (лише від тканини), якщо інше не задано в адмінці.
6. Ціна на картці товару показує **поточну** суму після вибору тканини (не лише «від», коли тканина вже обрана). У каталозі лишається «від …» = мінімум по тканинах.
7. У заявці «Замовити» обов’язково фіксуються: модель, **тканина**, **відтінок**, **ціна на момент заявки**, артикул варіанта (якщо є).

Де повний UI: §1.3 (сітка — лише відтінки/фото) і §4.4 (картка — тканина + відтінок + ціна).

## 4. Детальна карта кожної сторінки

### 4.1. Головна `/`

**Призначення:** бренд + вхід у продукцію.

**Блоки зверху вниз:**

1. Шапка (логотип ROSSA).
2. **Головний екран з відео** (єдине місце відео на сайті).  
   CTA: «Дивитись продукцію» → `/katalog/`.
3. **Наша продукція** — 3 плитки: **Дивани**, **Ліжка**, **Пуфи**.
4. **Хіти** — товари з міткою «Хіт» (з усіх категорій).
5. **Новинки** — товари з міткою «Новинка».
6. **Переваги** — 3–4 короткі тези.
7. Короткий блок «Про ROSSA» + кнопка на `/pro-nas/`.
8. Підвал.

---

### 4.2. Огляд продукції `/katalog/`

Плитки категорій 1 рівня: Дивани, Ліжка, Пуфи (фото + назва + перехід).

---

### 4.3. Сторінка категорії / підкатегорії

**Блоки:**

1. Хлібні крихти, напр.: Головна → Продукція → Дивани → Кутові.
2. Заголовок категорії + кількість моделей.
3. Для `/katalog/divany/`: додатково плитки підкатегорій **Модульні / Кутові / Прямі**.
4. Сортування: новинки / популярні / ціна ↑ / ціна ↓ / назва.
5. Фільтр наявності (за потреби).
6. Сітка карток (§1.3).
7. «Показати ще» або пагінація.

---

### 4.4. Картка товару `/tovar/{slug}/`

**Призначення:** одна модель (диван / ліжко / пуф) + вибір тканини/відтінку + заявка.  
**Подача:** галерея за відтінком, назва, ціна залежно від тканини (логіка §1.4).

**Блоки:**

1. Хлібні крихти з реальною категорією, напр.: Головна → Дивани → Кутові → Назва; або Головна → Ліжка → Назва.
2. Галерея фото обраного **відтінку** (окремі кадри моделі на цей колір; гортання, збільшення).
3. Назва, артикул варіанта (якщо є), наявність, підпис категорії.
4. **Крок 1 — Тканина:** список / чіпи доступних тканин. Вибір дорожчої тканини **збільшує** ціну одразу.
5. **Крок 2 — Відтінок:** кружечки кольорів (як у Pufetto) у межах обраної тканини. Клік → зміна фото галереї на фото цього відтінку.
6. Ціна: спочатку «від … грн» (мін. тканина); після вибору тканини — **актуальна сума** + коротка примітка («ціна залежить від тканини»).
7. Характеристики + опис (UA/RU). Додаткові варіанти (розмір / конфігурація) — якщо заведені в адмінці; також можуть впливати на ціну.
8. Кнопка **«Замовити»** (єдина дія покупки). Активна, коли обрані тканина і відтінок (якщо вони є в моделі).
9. Форма на цій же сторінці (модалка або блок):
   - **автопідстановка (readonly або приховані поля):** модель, тканина*, відтінок*, ціна на момент заявки*;
   - ПІБ*;
   - телефон*;
   - e-mail (за бажанням);
   - коментар;
   - спосіб отримання: **самовивіз / завантаження** або **власним авто**;
   - згода на обробку ПД*;
   - «Надіслати замовлення».
10. Після успіху → `/dyakuyemo/`.
11. Блок «Схожі товари» з тієї ж категорії (для диванів — з тієї ж підкатегорії); у схожих — ті самі кружечки в картках (§1.3).

### 4.7. Співпраця `/spivpratsya/` 

**Призначення:** умови для дилерів, салонів, дизайнерів, B2B-партнерів.

**Блоки:**

1. Заголовок і короткий вступ (чому співпрацювати з ROSSA).
2. Формати співпраці (картки: дилер / салон / дизайнер / гурт — тексти замовника).
3. Переваги партнера (опт, асортимент, підтримка — тексти замовника).
4. **Форма заявки на співпрацю:**
   - назва компанії / ПІБ*;
   - телефон*;
   - e-mail*;
   - місто;
   - тип співпраці (список);
   - повідомлення;
   - згода на обробку ПД*.
5. Заявка йде в адмінку з міткою джерела **«Співпраця»** (окремо від замовлень товарів) + сповіщення менеджеру.

## 6. Шлях клієнта

```
Головна (відео)
   → Продукція (Дивани / Ліжка / Пуфи)
      → [для диванів] Модульні | Кутові | Прямі
         → Сітка: прев’ю відтінків (кружечки) під фото
            → Картка однієї моделі
               → Тканина (ціна ↑/↓) → Відтінок (фото)
                  → «Замовити» (модель + тканина + відтінок + ціна)
                     → Форма
                        → «Дякуємо»
                           → Менеджер у адмінці
```

Паралельні шляхи:

- **Співпраця** → форма партнера → заявка з міткою «Співпраця».
- **Контакти** → форма питання → звернення з міткою «Контакти».

Один товарний візит = **одне замовлення однієї моделі** з фіксованими тканиною, відтінком і ціною (подальші уточнення — у коментарі або телефоном).
