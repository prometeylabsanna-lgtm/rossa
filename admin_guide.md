# Інструкція для сайту ROSSA

---

## 1. Вступ

### 1.1. Як увійти

1. Відкрийте посилання: **[https://rossamebel.com.ua/rossa-panel/](https://rossamebel.com.ua/rossa-panel/)**.
2. Введіть **ім’я користувача** і **пароль**, які вам видали.
3. Натисніть **Увійти**.

На сторінці входу також є перемикач **Світла / Темна / Система** — це лише вигляд панелі, на сайт клієнтів не впливає.

### 1.2. Огляд головного меню

Зліва — головне меню. Воно поділене на три блоки.

#### Сторінки сайту


| Пункт меню                    | Що змінює                                                   |
| ----------------------------- | ----------------------------------------------------------- |
| **Головна**                   | Тексти й фото на головній сторінці, слайди верхнього банера |
| **Переваги на головній**      | Картки переваг (під блоком про бренд)                       |
| **Про нас**                   | Сторінка «Про нас»: тексти, віхи історії, галереї           |

| **Доставка**                  | Текст сторінки доставки / отримання                         |
| **Оферта**                    | Текст публічної оферти                                      |
| **Політика конфіденційності** | Текст політики                                              |
| **Cookies**                   | Текст політики cookies                                      |
| **Шапка сайту**               | Логотип, телефони, соцмережі вгорі сайту                    |
| **Підвал сайту**              | Контакти, адреса, графік, карта, підписи внизу сайту        |




#### Каталог


| Пункт меню             | Що змінює                                                             |
| ---------------------- | --------------------------------------------------------------------- |
| **Каталог товарів**    | Товари: назва, ціна, фото, опис, кольори, тканини                     |

| **Відтінки**           | Конкретні відтінки всередині тканини (колір + міні-фото)              |

| Пункт меню              | Що змінює                           |
| ----------------------- | ----------------------------------- |
| **Замовлення**          | Заявки на товар із картки товару    |
| **Заявки на співпрацю** | Форми зі сторінки «Співпраця»       |
| **Заявки з контактів**  | Повідомлення зі сторінки «Контакти» |




### 1.3. Як влаштована форма редагування

У багатьох розділах зверху є **вкладки**:

- **Контент (ukr)** — українська версія (основна, її варто заповнювати завжди).
- **Контент (ru)** — російська версія (можна залишити порожньою; тоді на сайті підтягнеться український текст, де це передбачено).
- Інколи є окремі вкладки: **Слайди банера**, **Кольори товару**, **Оформлення** тощо.

Після змін натисніть **Зберегти** (внизу або зверху форми). Зміни з’являються на сайті одразу — додатково нічого робити не потрібно.

Поле **URL-адреса** (slug) часто сіре і заповнюється само з назви — його **не треба** вводити вручну.

## 2. Покрокові сценарії



### 2.1. Каталог і товари



#### Як додати новий товар

1. У лівому меню відкрийте **Каталог** → **Каталог товарів**.
2. У правому верхньому кутку натисніть **Додати товар** (або подібну кнопку «Додати»).
3. На вкладці **Контент (ukr)** заповніть:


| Поле                 | Що писати                                          | Обов’язково? |
| -------------------- | -------------------------------------------------- | ------------ |
| **Назва (ukr)**      | Назва моделі, як на сайті                          | Так          |
| **Артикул**          | Внутрішній код (якщо є)                            | Ні           |
| **Категорія**        | Основна категорія товару                           | Так          |
| **Тип**              | Підкатегорія зі списку (наприклад, «Прямі дивани») | Бажано       |
| **Базова ціна, грн** | Ціна без пробілів і копійок (ціле число)           | Так          |
| **Бейдж**            | NEW / TOP / Хіт — або порожньо                     | Ні           |
| **В наявності**      | Увімкнено = можна замовляти                        | —            |
| **Видимий**          | Увімкнено = товар показується на сайті             | —            |
| **Основне фото**     | Запасне фото, якщо для кольору ще немає галереї   | Бажано       |
| **Опис (ukr)**       | Текст опису (до ~500 символів)                     | Ні           |
| **Догляд (ukr)**     | Поради з догляду (до ~200 символів)                | Ні           |
| **Розміри (ukr)**    | Наприклад: `220×100×85 см`                         | Ні           |


1. За потреби відкрийте вкладку **Контент (ru)** і дублюйте тексти російською.
2. Нижче / на вкладках товару заповніть додаткові блоки (див. нижче).
3. Натисніть **Зберегти**.



#### Як змінити ціну

1. **Каталог** → **Каталог товарів**.
2. Знайдіть товар у списку (пошук зверху) і відкрийте його.
3. Змініть **Базова ціна, грн**.
4. Якщо ціна залежить від тканини — на вкладці **Ціни за категоріями тканини** вкажіть окрему **Ціну, грн** для потрібної тканини.
5. **Зберегти**.

> Якщо для тканини вказана окрема ціна — на сайті для цієї тканини покажеться вона, а не базова.



#### Як додати / змінити фото (галерея)

Фото галереї **не** в полі **Основне фото**. У кожного товару є вкладка **Фото за кольорами** (навіть якщо колір лише один).

1. Відкрийте товар.
2. Вкладка **Кольори товару** — додайте потрібні кольори → **Зберегти**.
3. Вкладка **Фото за кольорами** — зверху кружечки обраних кольорів (HEX зі **Стандартні кольори**).
4. Клацніть кружечок потрібного кольору — відкриються поля **Фото** + **Порядок** саме для нього.
5. Додайте кілька фото (менший порядок = раніше; перше = головне на сайті).
6. **Зберегти**.

На сайті фото цього кольору гортаються свайпом; на сторінці товару — ще й мініатюри.

**Основне фото** (вкладка **Контент (ukr)**) — лише запасний варіант, якщо для кольору ще немає фото в галереї.



#### Як додати кольори до товару

Спочатку переконайтеся, що потрібний колір є в **Каталог** → **Стандартні кольори**. Якщо ні — додайте його там (назва + колір пікером).

Потім у картці товару:

1. Вкладка **Кольори товару**.
2. Оберіть **Колір** зі списку.
3. За потреби змініть **Порядок** (менше число = вище в списку).
4. Залиште **Видимий** увімкненим.
5. **Зберегти**.
6. Вкладка **Фото за кольорами** — кружечок цього кольору → завантажте фото галереї.



#### Як додати характеристики (каркас, наповнення тощо)

1. Спочатку в **Каталог** → **Характеристики** мають бути назви рядків (наприклад, «Каркас»).
2. У картці товару відкрийте вкладку **Характеристики**.
3. Оберіть характеристику, впишіть **Значення (ukr)** (і за потреби російською).
4. **Зберегти**.



#### Як працювати з категоріями

1. **Каталог** → **Категорії**.
2. **Додати категорію** або відкрити існуючу.
3. **Назва (ukr)** — як у меню.
4. **Батьківська** — залиште порожньою для розділу 1 рівня; оберіть батька — якщо це підкатегорія.
5. **Порядок** — впливає на черговість у меню.
6. **Видима** — вимкніть, щоб тимчасово сховати розділ.
7. Підкатегорії можна додавати прямо в картці батьківської категорії (блок **Підкатегорії**).



#### Як керувати тканинами та відтінками

- **Тканини** — назва категорії тканини, **Націнка, грн** (додаткова сума до базової ціни, якщо немає окремої ціни в товарі), **Порядок**, **Видима**.
- **Відтінки** — прив’язка до тканини, назва, колір (**HEX** через пікер), за бажанням **Міні-фото кружечка**.

### 2.2. Контент і тексти на сторінках



#### Головна сторінка

1. **Сторінки сайту** → **Головна**.
2. На вкладці **Контент (ukr)** можна змінити, зокрема:


| Поле                                      | Де видно на сайті                  |
| ----------------------------------------- | ---------------------------------- |
| **Категорії (ukr)**                       | Заголовок блоку категорій          |
| **Хіти (ukr)**                            | Заголовок блоку популярних моделей |
| **Про ROSSA — заголовок / текст**         | Короткий блок про бренд            |
| **Заголовок / текст блоку «виробництво»** | Блок про майстерню                 |
| **Текст посилання «Про нас»**             | Підпис кнопки/посилання            |
| **Фото майстерні**                        | Зображення цього блоку             |
| **Текст банера-запрошення**               | Нижній заклик / банер              |


1. Вкладка **Слайди банера** — великі фото вгорі головної:
  - **Зображення** — обов’язкове для слайда.
  - **Підпис / alt** — короткий опис фото (для доступності та SEO).
  - **Порядок**, **Активний**.
2. Переваги окремо: **Сторінки сайту** → **Переваги на головній**
  (номер, заголовок, короткий текст до ~150 символів, порядок, видимість).
3. **Зберегти**.



#### Сторінка «Про нас»

1. **Сторінки сайту** → **Про нас**.
2. Заповніть **Заголовок**, **Підзаголовок**, **Текст**.
3. Блоки зі списками (кнопками «додати рядок»):
  - **Віхи** — рік + текст історії.
  - **Фото виробництва** — галерея.
  - **Логотипи (галерея)** — фото, рік, підписи (рік має збігатися з віхою, щоб логотип підтягнувся до неї).
  - Вкладка **Еволюція диванів** — заголовок і галерея.
4. **Зберегти**.



#### Сторінка «Співпраця»

1. **Сторінки сайту** → **Співпраця**.
2. Змініть заголовок, **Hero фото**, блок переваг, підтримку дилера, фото біля форми.
3. **Поля форми** — підписи й підказки полів заявки (укр / рос). Змінюйте лише тексти підписів, не ламайте структуру полів.
4. **Зберегти**.



#### Контакти

1. **Сторінки сайту** → **Контакти**.
2. Тут зазвичай лише **Заголовок** сторінки та **Заголовок форми**.
3. Телефони, адресу, e-mail змінюйте в **Шапка сайту** / **Підвал сайту** (див. нижче).



#### Доставка, оферта, політика, cookies

1. Відкрийте відповідний пункт у **Сторінки сайту**.
2. Змініть **Заголовок** і **Текст** (велике текстове поле з форматуванням).
3. Поле **Видима** — чи показувати сторінку.
4. **URL** не змінюйте — він зафіксований.
5. **Зберегти**.



#### Шапка сайту

1. **Сторінки сайту** → **Шапка сайту**.
2. Можна змінити:
  - **Логотип**
  - **Телефон 1 / 2 / 3**
  - Посилання **Telegram**, **Instagram**, **Facebook**, **TikTok**
3. Вкладка **Оформлення** (кольори шапки) — див. розділ «Чого краще не робити».
4. **Зберегти**.



#### Підвал сайту

1. **Сторінки сайту** → **Підвал сайту**.
2. Тут же телефони, e-mail, соцмережі, плюс:
  - **Адреса**, **Графік**
  - **Підпис у підвалі**
  - **Карта / салон** (зображення)
  - Короткі підписи **Гарантія**, **Доставка**
3. Російські варіанти — на вкладці **Контент (ru)**.
4. **Зберегти**.

> Телефони й соцмережі спільні для шапки й підвалу: зміна в одному з цих розділів оновлює загальні контактні дані сайту.

### 2.3. Робота з медіафайлами (фото)



#### Загальні правила

- Допустимі звичайні формати фото: **JPG, PNG, WebP** (система сама оптимізує зображення).
- **Максимальний розмір файлу: 8 МБ** на одне фото. Якщо більше — стисніть файл перед завантаженням.
- Дуже широкі фото система зменшить (орієнтир верхньої межі за шириною — близько **1600 px**). Краще одразу завантажувати якісне, але не «гігантське» зображення.
- Краще однакова «рамка» й освітлення в серії фото товарів — так каталог виглядає охайніше.



#### Рекомендації за типом фото


| Де використовується                                     | Рекомендація                                                                                                     |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Слайди банера** на головній                           | Широке горизонтальне фото, орієнтовно **1600×900** або подібне (16:9). Без дрібного тексту на самому зображенні. |
| **Основне фото товару** / фото кольорів                 | Чітке фото моделі, орієнтовно **1200–1600 px** по довшій стороні. Фон нейтральний.                               |
| **Фото майстерні**, hero «Співпраця», галереї «Про нас» | Горизонтальні або квадратні якісні фото, до **1600 px** за шириною.                                              |
| **Міні-фото кружечка** (відтінок)                       | Невеликий квадратний свотч, достатньо **200–400 px**.                                                            |
| **Логотип**                                             | PNG з прозорим фоном або чіткий WebP/PNG; не розтягуйте дрібний файл на весь екран.                              |
| **Карта / салон**                                       | Зрозуміла схема або фото салону, ширина до **1600 px**.                                                          |




#### Як завантажити правильно

1. Відкрийте потрібний запис (товар, сторінку тощо).
2. Натисніть кнопку вибору файлу біля поля фото.
3. Оберіть файл з комп’ютера.
4. Дочекайтеся прев’ю (якщо воно з’являється).
5. Обов’язково натисніть **Зберегти** — інакше фото не застосується.

### 2.4. Замовлення та звернення клієнтів

Усі заявки з сайту збираються в блоці **Заявки**.

#### Замовлення товарів

1. **Заявки** → **Замовлення**.
2. У списку видно: дату, модель, тканину, відтінок, ціну, ПІБ, телефон, **статус**.
3. Відкрийте рядок, щоб побачити коментар, e-mail, спосіб отримання тощо.
4. Статус можна змінити прямо в списку або всередині картки:
  - **Нове** → **В обробці** → **Узгоджено** → **Виконано**  
  - або **Скасовано**
5. Після зміни статусу натисніть **Зберегти** (якщо редагували всередині картки). У списку при `list_editable` збережіть зміни списку кнопкою збереження внизу, якщо вона з’явиться.



#### Заявки на співпрацю

1. **Заявки** → **Заявки на співпрацю**.
2. Дивіться компанію, телефон, e-mail, тип співпраці, статус.
3. Оновлюйте статус так само, як у замовленнях.



#### Звернення з контактів

1. **Заявки** → **Заявки з контактів**.
2. Ім’я, телефон, повідомлення, статус.
3. Опрацюйте звернення й змініть статус.

**Пошук:** у кожному списку зверху є рядок пошуку (за телефоном, ім’ям, назвою моделі тощо).  
**Фільтри:** праворуч / збоку можна відфільтрувати за статусом.

## 3. Корисні поради та «Чого краще не робити»



### 3.1. Що варто робити

- Завжди заповнюйте **українські** поля — це основна мова сайту.
- Перед публікацією нового товару перевірте: **категорія**, **ціна**, **основне фото**, увімкнено **Видимий**.
- Щоб тимчасово сховати товар — вимкніть **Видимий**, не видаляйте одразу.
- Для акційних міток використовуйте **Бейдж** (NEW / TOP / Хіт).
- Після збереження відкрийте відповідну сторінку сайту в новій вкладці й перевірте результат.



### 3.2. Чого краще не чіпати самостійно


| Що                                                                   | Чому                                                                     |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Поле **URL-адреса** (slug)                                           | Формується автоматично; ручна зміна може зламати старі посилання         |
| Вкладка **Оформлення** (кольори фону, тексту, підсвітки)             | Легко зіпсувати вигляд сторінки; змінюйте лише за узгодженням з дизайном |
| Кольори в **Шапці** / **Підвалі** (оформлення)                       | Те саме — краще не експериментувати без потреби                          |
| Видалення категорій, тканин, кольорів, які вже прив’язані до товарів | Може заблокувати збереження або «зламати» картки                         |
| Довгі тексти понад підказку біля поля                                | Система може не зберегти запис (ліміт символів для акуратної верстки)    |
| Технічні розділи поза описаним меню                                  | Не потрібні для щоденної роботи з контентом                              |




### 3.3. Якщо зміни «не видно» на сайті

Зазвичай достатньо:

1. Переконатися, що натиснули **Зберегти**.
2. Оновити сторінку сайту (на телефоні — закрити й відкрити знову; на комп’ютері — оновлення сторінки).
3. Перевірити, що запис **видимий / активний** (галочки **Видимий**, **Активний**, **В наявності**).
4. Для товару — що обрано правильну **категорію**.

Окремо очищати кеш не потрібно: після збереження контент оновлюється на сайті.
